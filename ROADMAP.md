# Remaining work, ordered by consequence

## Before any real health information

Independent threat model and penetration test; clinical/consent/legal review; infrastructure controls and contracts; verified professional identity; managed onboarding and recovery; revocation race analysis; external audit retention; operational staffing; tested backup/restore and deletion policies; complete accessibility audit.

## Clinical content

Verify rights and exact sources for an appropriate initial established measure. Add version-specific pure scoring with independent reference cases. Add only reviewed interpretations. Do not convert current demo prompts into a named instrument by renaming them.

## Product depth

- Generic clinician-only questionnaire editing and arbitrary read-only calculated-field rendering.
- Server-produced accessible/tagged PDF generation; current output is HTML plus browser Print / Save as PDF.
- Account invitations, verified credential administration, session inventory, and managed identity federation.
- Audited deletion execution and retention scheduler after legal policy review.
- Resource re-verification workflow and organization-specific monitoring configuration, only when backed by a real service.
- Report-template versioning, participant-controlled release rules beyond assigned reviewer access, and translation review.
- Mobile/tablet visual QA, assistive technology sessions, and load testing.

## Intentionally excluded

Autonomous diagnosis, fabricated clinical norms, diagnostic probabilities, hidden emotion detection, automatic emergency contact, minors without reviewed safeguarding, automatic medication advice, and external AI processing by default.
