# Required qualified clinical and organizational review

Release 0.1 is for synthetic demonstrations only. Independent review must precede any real assessment deployment.

| Area                  | Required decision / evidence                                                                                                                                                    |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Intended use          | Define service population, exclusion criteria, setting, staff responsibilities, and whether an assessment is supervised.                                                        |
| Professional access   | Verify identity, credentials, scope of practice, assignment rules, and supervision. No demo reviewer has asserted credentials.                                                  |
| Consent               | Approve plain-language purpose, access, data use, retention, withdrawal, confidentiality limitations, monitoring, review times, and jurisdiction-specific terms.                |
| Instrument rights     | Verify exact wording, version, permitted administration, license, translation, scoring, and population. No established instrument is included yet.                              |
| Scoring               | Independently verify reference cases, missing-item rules, boundaries, cutoffs, and interpretation limitations before implementing any clinical result.                          |
| Participant language  | Review respectful, non-prescriptive summaries and uncertainty. No diagnosis or care recommendation should follow solely from screening.                                         |
| Safety                | Define any future monitoring hours, review times, triage protocols, escalation, consent, legal duties, and audit requirements. Current demo performs no monitoring or outreach. |
| Resources             | Independently verify official regional resources and source dates; approve the 180-day freshness policy. No geolocation is collected.                                           |
| Clinical observations | Review the mental-status template and source labels. No observations are inferred automatically.                                                                                |
| Reports               | Approve report structure, credentials, signature assurance, release rules, amendments, and participant export scope.                                                            |
| Adult eligibility     | Review self-attestation limitations. Minor participation is unsupported.                                                                                                        |
| Privacy               | Review deletion, legal retention, backups, access logging, operator access, and breach response.                                                                                |
| Accessibility         | Perform screen-reader, keyboard, zoom, cognitive accessibility, contrast, language, and printable-output review with representative users.                                      |

Completing a software checkbox does not satisfy any of these reviews. Keep documented approval evidence outside public source control. Do not enter reviewer names or dates into the instrument registry until an actual review has occurred.
