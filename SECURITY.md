# Security reporting and support boundary

Clearframe 0.1 is a synthetic-data reference application, not an independently audited clinical product.

Do not report vulnerabilities with patient information, secrets, or exploit credentials in public issues. After creating the GitHub repository, enable GitHub private vulnerability reporting and use its **Security → Report a vulnerability** flow. If it is unavailable, contact the repository owner through an independently verified private channel. No security mailbox or guaranteed response time is claimed here.

Do not deploy for real health information until the full review in `docs/DEPLOYMENT.md` is complete. See `docs/SECURITY-PRIVACY.md` for controls, assumptions, residual risks, and data-handling requirements.
